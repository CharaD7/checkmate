# CheckMate

A **full‑stack, mobile‑responsive, accessibility‑first** plagiarism‑checking platform built with NestJS (backend) and React + TypeScript (frontend). 

## Features
- Email/password authentication with JWT, refresh tokens, and **MFA (TOTP)**
- Password reset via email
- Social login (Google OAuth)
- Document upload (PDF/DOCX) → S3/MinIO storage
- Plagiarism detection microservice (shingling + MinHash, pluggable to external APIs)
- Detailed similarity reports with highlighted matches
- Admin dashboard & role‑based access
- WCAG 2.1 AA compliant UI, mobile‑first, screen‑reader friendly
- CI/CD with GitHub Actions, Docker, optional Kubernetes deployment

## Getting started (local development)
1. **Prerequisites**: Docker & Docker‑Compose, Node 18+, Git.
2. Clone the repo and `cd CheckMate`.
3. Install root dependencies:
   ```bash
   npm install
   ```
4. Start the supporting containers:
   ```bash
   docker-compose up -d
   ```
   This brings up PostgreSQL and MinIO.
5. Run backend services:
   ```bash
   cd apps/backend && npm run start:dev   # NestJS dev server (http://localhost:3000)
   cd ../detection && npm run start:dev   # Detection microservice (http://localhost:4000)
   ```
6. Run the frontend:
   ```bash
   cd apps/frontend && npm start   # CRA dev server (http://localhost:3001)
   ```
7. Open the UI, register, enable MFA, upload a document, and view the similarity report.

## Scripts
- `npm run lint` – Lint all workspaces.
- `npm run test` – Run Jest tests.
- `npm run build` – Build both backend and frontend for production.
- `npm run start` – Start production containers via Docker.
